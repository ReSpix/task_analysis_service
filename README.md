# Сервис аналитики задач для Asana

Система сбора и агрегации метрик из Asana с отправкой уведомлений в Telegram.
Разработана в рамках учебной практики для ООО «Первый Бит».
Позволяет отслеживать сроки, загрузку сотрудников и статистику по этапам, недоступные во встроенной аналитике Asana.

### Ключевые возможности
- Отслеживание событий Asana в реальном времени
- Агрегация задач в веб-интерфейсе: текст, исполнитель, история статусов
- Telegram-бот с оперативными уведомлениями по выбранным событиям
- Гибкое развёртывание: Docker или Windows сервис (NSSM)

### Стек технологий
- Бэкенд: Python, FastAPI, SQLAlchemy (async), Aiogram
- БД: SQLite
- Инфраструктура: Docker, Windows service
- Архитектура: RESTful API, Event-Driven, Webhooks

### Как это работает
Сервис непрерывно с небольшим интервалом отправляет запросы к Asana для получения событий на досках 
(создание/удаление задач, назначение исполнителей, изменение статусов, тегов, итд), 
валидирует входящие события и сохраняет их в SQLite базу данных. 
Агрегированные данные доступны через веб-интерфейс.
Telegram-бот отправляет уведомления о выбранных событиях.


### Запуск
Docker:
```bash
docker-compose up
```
Windows:
```powershell
service_install.bat
```
*создание .env файлов не требуется, все ключи настраиваются через веб-интерфейс*

После запуска по адресу `localhost:8000` доступен веб-интерфейс.

### Результаты
- Исключён ручной сбор отчётов менеджерами
- Увеличена скорость реагирования на важные события (сообщения Телеграм вместо ручной проверки канбан-досок)
